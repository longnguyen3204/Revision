# Revision

## Daily Routine
- Mở máy, **git pull** để cập nhật code mới nhất về máy.
- Tạo file/folder mới cho bài học/bài tập ngày hôm đó
- Cuối buổi học: **git add .** -> **git commit -m "Noi dung bai hoc nay"** -> **git push**.

## Tuần 2: Tư duy Hướng đối tượng (OOP)
Chuyển đổi tư duy từ viết code tuần tự sang mô hình hóa các thực thể.

### Ngày 8: 
- [X] Class và Object. Định nghĩa các thuộc tính (attributes) và phương thức (methods) cơ bản. Constructors & Destructors.

### Ngày 9: 
- [X] Tính đóng gói (Encapsulation). Sử dụng access modifiers (private, public, protected) và viết các hàm getter/setter.

### Ngày 10:

### Ngày 13:

### Ngày 14: 
- Commit code bài OOP. Chuyển về branch main (git checkout main) và gộp code vào (git merge feature/oop_practice). Push toàn bộ lên GitHub.
